> **Proyecto educativo** — SENA | Tecnólogo en Análisis y Desarrollo de Software (ADSO)

Aplicación web para gestionar procesos electorales del gobierno escolar en instituciones
educativas de Colombia, con énfasis en seguridad, transparencia y sistematización del voto.
